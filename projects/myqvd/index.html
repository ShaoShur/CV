01 / ЗАЧЕМ

Посмотреть QVD
без лишней инфраструктуры.

Системный WebView отвечает за интерфейс, Rust читает QVD через OpenQVD, а frontend получает только метаданные и запрошенную страницу строк.

01

Локальность

Файл не отправляется на внешний сервер. Чтение и работа с содержимым выполняются на компьютере пользователя.

02

Понятная структура

Имя таблицы, число строк, поля, cardinality, размер файла и технические метаданные собраны в одном интерфейсе.

03

Безопасный Save As

Изменённый заголовок сохраняется в новый QVD, бинарное тело копируется потоком, а результат повторно валидируется.

02 / MVP

Что уже работает.

Текущая версия сосредоточена на прозрачном чтении QVD и контролируемом редактировании метаданных.

READ

Выбор локального .qvd

Системный диалог открытия файла и чтение формата в Rust с помощью OpenQVD.

EXPLORE

Поля и cardinality

Список полей с техническими характеристиками и возможностью временно скрыть колонку.

DATA

Таблица по 250 строк

Постраничный просмотр значений без передачи всего набора данных во frontend.

DUAL

Qlik dual values

Текстовая часть показывается пользователю, числовая остаётся сохранённой в модели.

METADATA

NumberFormat и Tags

Просмотр известных метаданных таблицы и полей, включая техническую структуру заголовка.

ADVANCED

Исходный XML

Продвинутый режим просмотра и защищённого редактирования XML-заголовка QVD.
